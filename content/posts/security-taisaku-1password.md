こんにちは！ドタバタ母さんです。

この1週間、**セキュリティ対策**をしていました。

毎日コツコツ、**寝る前や出勤前の時間**を使って、使い回していたパスワードを作り直しました。2段階認証も、パスキーも設定しました。位置情報もマイクもカメラも見直して、使っていないアプリも消しました。

**やりきったつもりでいました。**

ところが、最後に見落としが見つかりました。

**1Passwordの復元コードが、パソコンのダウンロードフォルダに置いたままでした。**

金庫の鍵を、玄関に置いていたようなものです。

その話も含めて、全部書きます。

## 先に言っておきます。私は詳しくありません

はじめに、正直なところを。

**私は、エクセルの表計算ができません。**

文章を打ち込むことはできますが、それ以外は本当に知識がありません。関数もよく分からないまま、仕事では足し算と平均くらいしか使えない人間です。

**そんな私でも、できました。**

やり方は後半に書きます。

## きっかけ：1Passwordを半年前に入れていました

半年前、パスワード管理アプリの**1Password**を導入しました。

導入したのはいいのですが、**入れただけで満足していました。**

新しく登録するサービスは1Passwordで管理するようになったものの、**昔から使っているものは、昔のままの使い回しパスワード**でした。

## 使い回しが「一覧で」分かります

1Passwordには、こういう機能があります。

- **使い回しているパスワードの一覧**
- **強度が弱いパスワードの一覧**
- **2段階認証を設定できるのに、していないサービスの一覧**

**一目で分かります。**

自分がどれだけ危ない状態だったか、数字で突きつけられる感じです。

**これが、やる気になった理由**でした。「なんとなく不安」ではなく、**「この◯件を直せばいい」**とはっきりするので。

## 1週間、寝る前と出勤前にやりました

一度に全部やろうとすると、絶対に終わりません。

なので、**毎日少しずつ**にしました。

- **寝る前**に数件
- **出勤前**に数件

[大掃除を小分けにする](/posts/koji-souji-washitsu/)のと、同じやり方です。「今日は3件だけ」と決めると、気が重くなりません。

### 重要なものから手を付けました

全部を同じ重さで扱うと、途中で力尽きます。

**優先順位をつけました。**

1. **Appleアカウント・Googleアカウント** ← ここが破られると全部つながります
2. **お金に関わるもの**（銀行、証券、カード）
3. **メール**
4. その他

**上の3つだけでも、やる価値があります。**

### 重要なものは、2段階認証とパスキー

パスワードを強くするだけでなく、**2段階認証**も設定しました。

パスワードが漏れても、**それだけでは入れない**ようにする仕組みです。

**パスキー**が使えるものは、そちらにしました。パスワードを入力せず、顔や指紋で入れるものです。

## 思わぬ副産物：不要な銀行とカードが洗い出せました

これは予想していませんでした。

**全部のサービスを順番に見ていくと、「これ、もう使っていない」というものが出てきます。**

- 使っていない銀行口座
- 持っているだけのクレジットカード

**使っていないものは、守る必要もありません。** 解約すれば、管理するものが1つ減ります。

[使っていない口座を解約した話](/posts/mishiyou-kouza-kaiyaku/)を前に書きましたが、あれも同じ流れでした。

## そして、見落としが見つかりました

ここからが本題です。

一通り終わったあと、**パソコンのダウンロードフォルダ**を確認してもらいました。

出てきたのが、これです。

```
1Password復元コード.txt
1Password Emergency Kit ....pdf
```

**1Passwordの金庫を開けられる情報**でした。

### 何がまずいのか

1Passwordは、**マスターパスワード**と**シークレットキー**の2つで守られています。

Emergency Kitには、**そのシークレットキーが載っています。**

つまり——

**パソコンを盗まれたら、せっかく強くしたパスワードが全部まとめて見られる可能性がある。**

1週間かけてやったことが、**この1ファイルで台無しになるところ**でした。

### しかも、公式は「印刷して」と言っています

あとで知りましたが、**Emergency Kitは印刷して保管する前提**で作られています。

ダウンロードしたまま置いておくものでは、**そもそもありませんでした。**

私は、**ダウンロードしたことすら忘れていました。**

## やったこと

1. **PDFを印刷する**
2. **マスターパスワードの欄を、手書きで埋める**（印刷されません）
3. **通帳と印鑑と同じ場所にしまう**
4. **パソコンから完全に削除する**

### 手書きの欄について

マスターパスワードの欄は、**印刷では空欄**です。自分で書き込みます。

ここは迷いました。**書けば、紙を見た人に金庫を開けられます。**

でも、**書かないほうが危ない**と判断しました。

**1Passwordは、マスターパスワードを忘れたら本当に終わりです。** サポートに連絡しても開けてもらえません。運営側も知らない作りだからです。

| | |
|---|---|
| 紙を盗まれる | 家に侵入される必要がある |
| **忘れる** | **普通にありえる** |

後者のほうが現実的だと思ったので、書きました。

### しまう場所

**通帳と印鑑と同じ場所**にしました。

我が家は、もともと**印鑑と通帳を一緒に保管**しています。場所が決まっていて、迷わず取り出せる。**その仕組みに乗せただけ**です。

### 削除は、ゴミ箱に入れるだけでは足りません

これも教わりました。

ゴミ箱に入れても**中に残ります**し、空にしても**復元ソフトで読めることがあります。**

パソコンに詳しい方なら、**上書きしてから削除する方法**があります。私はそのやり方を教えてもらって実行しました。

## ついでに、スマホも見直しました

パソコンの次は、スマホです。

### 位置情報

**設定 → プライバシーとセキュリティ → 位置情報サービス**

**「常に」になっているアプリ**を探して、**「使用中のみ」**に下げました。

「常に」は、**アプリを開いていなくても居場所が送られ続ける**設定です。本当に必要なのは、ナビや天気くらいでした。

### 写真

**フルアクセス**になっているアプリを減らしました。

残したのは、**バックアップ用の2つと、画像を渡すアプリ1つ**だけ。あとは**「写真を選択」**にしました。投稿のときに選べば済むからです。

子どもの写真が大量に入っている端末なので、ここは効きます。

### マイク・カメラ・連絡先

使っていないアプリは、全部オフにしました。

**連絡先**は、LINEと楽天リンクだけにしました。通話とメッセージに必要なものだけです。

### トラッキング

**設定 → プライバシーとセキュリティ → トラッキング**

これは**オフ**にしました。アプリをまたいだ行動の追跡が止まります。

### 使っていないアプリは消しました

古いブログのアプリなど、**もう使わないもの**を削除しました。

**使っていないアプリは、置いてあるだけでリスク**です。更新が止まって脆弱性が残りますし、ログイン状態や権限も生きたままだからです。

## 費用のこと

最初は、**1Passwordの費用が高いと思っていました。**

でも、トータルで考えると**安い**と思えるようになりました。

**パスワードを覚える手間がないんです。**

- 全部ちがうパスワードにできる
- 覚えなくていい
- どこが危ないか教えてくれる

この3つを人力でやろうとしたら、たぶん無理です。

※ 料金は変わるので、**公式サイトでご確認ください。**

## エクセルもできない私が、どうやったか

最後に、いちばん伝えたいことを。

**私は、何をどうやったらいいか分かりませんでした。**

「セキュリティ対策をしましょう」と言われても、何から手を付けるのか、どこまでやれば十分なのか、まったく見当がつきませんでした。

そこで、**AIに相談しながら進めました。**

- 「何から手を付ければいい？」
- 「この設定はどこにある？」
- 「これは消してもいい？」

**壁打ちしながら聞いていくと、手順を教えてくれます。**

[訪問看護の事務作業をAIで減らした話](/posts/houmonkango-ai-jimu/)でも書きましたが、**知識がなくても、聞ける相手がいれば進められます。**

今回のダウンロードフォルダの件も、**自分では絶対に気づけませんでした。**

## 今からでも遅くありません

というわけで、この1週間の記録でした。

全部やる必要はないと思います。でも、**重要なところから**だけでも、やる価値があります。

- **Appleアカウント**
- **Googleアカウント**

この2つが破られると、**ほかのサービスが芋づる式につながります。** まずはここだけでも、パスワードを強くして2段階認証を設定する。

それだけで、だいぶ違います。

そして——

**もし復元コードやEmergency Kitをダウンロードしたままなら、今日そこを確認してください。**

私は1週間やりきったつもりで、**いちばん大事な鍵を置きっぱなしにしていました。**
