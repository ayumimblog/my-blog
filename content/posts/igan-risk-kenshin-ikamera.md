こんにちは！ドタバタ母さんです。

**数年ぶりに胃カメラ**を受けてきました。

今回は、静岡市の**「胃がんリスク検診」**という制度を使いました。費用は**4,000円**です。

そして、**鼻からの胃カメラは初めて**でした。

先に正直に書きます。

**痛かったです。**

ネットで調べると「鼻からなら楽」と書いてあることが多いのですが、私はそうではありませんでした。**その話も含めて、全部書きます。**

## そもそも、この検診を知りませんでした

きっかけは、**近所のクリニックへの問い合わせ**でした。

「胃カメラを受けたい」と電話したら、**「リスク検診がありますよ」**と教えてもらったんです。

**自分からは、たどり着けていませんでした。**

## 静岡市の「胃がんリスク検診」とは

調べてみたら、こういう制度でした。

| | |
|---|---|
| 開始 | **令和5年度から** |
| 対象 | **35歳〜49歳の期間に、生涯1回だけ** |
| 内容 | **ABC検査（血液）＋ 内視鏡検査**のセット |
| 目的 | 将来の胃がんリスクを判定する |
| 費用 | **4,000円**（処置が必要な場合は追加） |

（[静岡市：胃がんリスク検診について](https://www.city.shizuoka.lg.jp/695_000001_00105.html)）

### ここが大事です。「1回だけ」です

毎年受けるものではありません。

**35歳から49歳のあいだに、1回。**

つまり、**50歳になったら受けられません。** 知らないまま年齢を過ぎてしまう人が、けっこういるのではないかと思います。

### 受けられない場合もあります

次に当てはまる方は対象外です。

- 過去に静岡市でこの検診を受けた
- 胃がんと判定されたことがある
- 胃の切除手術を受けたことがある
- **すでにピロリ菌を除菌した**
- 胃潰瘍・十二指腸潰瘍の治療中
- 腎不全の治療中・経過観察中
- **胃酸分泌抑制剤（PPI）を服用中**

市と医師会で書き方が少し違うので、**申し込む前に確認**してください。

## 申し込みの手順

ここが、知らないと詰まるところです。

**クリニックに行く前に、役所への申請が必要**でした。

1. クリニックに問い合わせる（この検診をやっているか確認）
2. **自分で役所に連絡して、受診券を申請する**
3. しばらくすると**受診券が届く**
4. 受診券を持って、**クリニックに予約の連絡**

**2を飛ばすと受けられません。** 私も教えてもらわなければ、ここでつまずいていたと思います。

申請先は**健康づくり推進課**です。

## クリニックは「胃カメラが上手」で選びました

今回行ったのは、**かかりつけではない近所のクリニック**です。

決め手は単純でした。

**母親が通院していて、「あそこは胃カメラが上手」と聞いていたから。**

検査を受ける側としては、**技術が確かなところ**がいちばん安心です。口コミが身内から聞けたのは大きかったです。

## 鎮静剤なし、鼻からの胃カメラでした

このクリニックは、**鎮静剤を使わない方針**でした。

なので、**意識がはっきりしたまま**受けます。

### 麻酔はゼリー状で、鼻に入れます

ゼリー状の麻酔薬を鼻に注入して、**10分以上待ちました。**

待っているあいだに、**喉の奥が麻痺してきます。**

### 呼吸のしやすい顔の向きを、自分で探しました

ここが、やってみて初めて分かったことです。

喉の奥が麻痺してくると、**体勢によっては呼吸がしにくくなります。**

なので、**自分で楽な顔の向きを探していました。**

苦しいまま我慢するのではなく、**「この向きなら呼吸しやすい」という位置を見つける。** これは、知っておくと違うと思います。

## 正直に書きます。痛かったです

さて、本題です。

**鼻の穴が狭いみたいで、鼻の奥がずっと痛かったです。**

ネットで調べると「鼻からなら楽」「オエッとならない」と書いてあります。でも**それは、鼻の通りに余裕がある人の話**なのだと思います。

私の場合は、**検査のあいだずっと痛い**という状態でした。

### 終わったあと、鼻血が出ました

そして検査が終わったあと、**鼻血が出ました。**

それだけでなく、**夜まで血の混じった鼻水や痰**が出ていました。

これは想定していませんでした。

### 胃の中は「痛み」ではなく「違和感」

一方、カメラが胃や十二指腸に入っているときは、**痛みではありませんでした。**

**お腹を掻き回されているような痛み**ではなく、**違和感**という感じです。

つまり、

- **鼻** → 痛い
- **胃・十二指腸** → 違和感

という分かれ方でした。

## 自分の胃の中が見られる、はずでした

鎮静剤を使っていないので、**意識があります。**

なので、**余裕があれば自分の胃の中の映像を見ることができます。**

せっかくなので見ようと思っていました。自分の体の中をリアルタイムで見るなんて、なかなかない機会です。

ところが——

**看護師さんが、ちょうど画面の前に立っていました。**

**見えませんでした。**

鼻は痛いし、画面は見えないし。まあ、看護師さんも仕事をしているだけなので仕方ないのですが、**ちょっと残念でした。**

これから受ける方は、**「見たいです」と先に伝えておく**といいかもしれません。

## かかった時間

| | |
|---|---|
| 全体 | **1時間程度** |
| 麻酔が抜けるまで | 検査終了後**1時間弱** |

検査そのものより、**前後の待ち時間**が長い印象でした。

## 終わったあとの体調

ここも、知っておくと予定が立てやすいと思います。

### お昼は、まともに食べられませんでした

**胃のムカムカ感が消えませんでした。**

お昼に食べられたのは、**ヨーグルトとバナナ程度**です。

### 夜には、普通に食べられました

夕方以降は回復して、**夜は普通に食べられました。**

なので、**当日の昼は軽めのものを用意しておく**といいと思います。「終わったら外で食べよう」と思っていると、たぶん無理です。

## 受けてみて思ったこと

### ① 知らないと、受けられない制度でした

私はたまたま、**クリニックへの問い合わせで教えてもらいました。**

市の広報には載っているのだと思いますが、**自分から探していなければ気づけなかった**と思います。

そして**35歳〜49歳で1回だけ。** 気づかないまま50歳になると、その機会は消えます。

### ② 4,000円で、内視鏡まで受けられます

血液検査だけでなく、**内視鏡まで入っての4,000円**です。

自費で胃カメラを受けることを考えると、**かなり安い**と思います。

### ③ 「楽」とは限らないことも、知っておきたい

鼻からの胃カメラは、**人によって負担がかなり違う**のだと思います。

私は痛かったですが、平気な人もいるはずです。**鼻の通りの個人差**が大きいのだと思います。

これから受ける方には、**「楽だと聞いていたのに」と驚かないでほしい**ので、正直に書きました。

### ④ 鎮静剤を使う施設もあります

今回は使わない方針のクリニックでしたが、**鎮静剤を使うところもあります。**

鎮静剤を使うと、眠っているあいだに終わります。ただし、**その日は車の運転ができません。**

**どちらがいいかは、施設に確認してから決める**のがいいと思います。

## 早期発見の話

せっかくなので、調べたことも書いておきます。

胃がんの5年生存率は、**見つかった段階で大きく変わります。**

| ステージ | 5年生存率 |
|---|---|
| **I** | **92.8%** |
| II | 67.2% |
| III | 41.3% |
| IV | **6.3%** |

（国立がん研究センター、2014〜2015年診断・全国447施設126,675例の集計）

**ステージIとIVで、15倍の開き**があります。

### 女性の受診率は、半分以下です

国民生活基礎調査（2025年）の胃がん検診の受診率です。

| | 1年間 | 過去2年間 |
|---|---|---|
| 男性 | 48.8% | 55.9% |
| **女性** | **38.3%** | **46.5%** |

（[社会保険研究所](https://media.shaho.co.jp/n/ndbfaee6c16ed?gs=3a75fe65e8f0)）

**女性のほうが、10ポイント低い**です。

子どもの検診や予防接種には必死になるのに、**自分のことは後回しになりがち**ですよね。私もそうでした。胃カメラ、数年ぶりでしたから。

あのとき予約しておいてよかったな、と思っています。
